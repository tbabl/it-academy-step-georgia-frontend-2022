## Description

This HTML project focuses on creating various **form elements** and understanding their functionality. The purpose of this project was to practice implementing different types of forms, input fields, and form controls while maintaining proper HTML structure and validation.

- **`index.html`**: The main page contains registration form with various input types, including different input types, radio buttons, checkboxes, dropdowns. Demonstrates proper form validation, and form submission handling.

> This page is not optimized for mobile devices. For the best experience, please view it on a desktop browser.

## HTML Tags Used

### Form Elements

- `<form>`: The container element for all form controls
- `<input>`: For various types of input fields
- `<label>`: To associate text labels with form controls
- `<select>`: For dropdown menus
- `<option>`: Individual options within select elements
- `<textarea>`: For multi-line text input
- `<button>`: For form submission and reset buttons
- `<fieldset>`: To group related form elements
- `<legend>`: To provide a caption for fieldset elements

### Input Types

- `type="text"`: For single-line text input
- `type="email"`: For email addresses
- `type="password"`: For password input
- `type="number"`: For numeric input
- `type="tel"`: For telephone numbers
- `type="date"`: For date selection
- `type="file"`: For file uploads
- `type="radio"`: For single selection options
- `type="checkbox"`: For multiple selection options
- `type="submit"`: For form submission buttons
- `type="reset"`: For form reset buttons

### Form Attributes

- `required`: To mark fields as mandatory
- `placeholder`: To provide input hints
- `pattern`: For input validation patterns
- `min` and `max`: For numeric range validation
- `maxlength`: To limit input length
- `autocomplete`: To control browser autocomplete behavior
