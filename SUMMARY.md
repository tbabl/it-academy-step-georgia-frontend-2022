# შეჯამება / Repo Summary

ეს რეპოზიტორი შეიცავს HTML დავალებებს, რომლებიც ორიენტირებულია ფორმებისა და ცხრილების შექმნაზე.  
პირველ რიგში, წარმოდგენილია სტუდენტის რეგისტრაციის ფორმა მრავალფეროვანი ველებითა და HTML5 ვალიდაციით.  
ასევე ნახავთ ცხრილების მაგალითებს, სადაც გამოყენებულია სხვადასხვა სტრუქტურა, ტეგები და ელემენტარული CSS სტილიზაცია.

მთავარი ფოლდერები და ფაილები:

- `student_registration_form/index.html` – სტუდენტის რეგისტრაციის ფორმა მრავალფეროვანი ველებითა და ვალიდაციით.
- `tables/index.html` – ორი ცხრილი: დამფუძნებლები და მათი ხელფასები, სემინარის განრიგი.

> [!NOTE]
> სრული აღწერილობებისთვის იხილეთ შესაბამისი .md ფაილები, რომლებიც თან ახლავს თითოეულ დავალებას.

## [![Tables](https://img.shields.io/badge/Tables-Preview-cyan)](https://tbabl.github.io/it-academy-step-georgia-frontend-2022/assignment_02/tables/)

This repository contains HTML assignments focused on creating forms and tables.  
First, you will find a student registration form with various input types and HTML5 validation.  
There are also examples of tables demonstrating different structures, table tags, and basic CSS styling.

Main folders and files:

- `student_registration_form/index.html` – Student registration form with multiple input types, validation, and form controls.
- `tables/index.html` – Two tables: Founders and their salaries, and a seminar schedule.

> For full descriptions, see the accompanying .md files included with each task.
