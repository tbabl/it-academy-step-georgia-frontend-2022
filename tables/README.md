# დავალება 2.1: ცხრილებთან მუშაობა HTML-ში

[![Live Demo](https://img.shields.io/badge/Live-Demo-purple)](https://tbabl.github.io/it-academy-step-georgia-frontend-2022/assignment_02/tables/)

## აღწერა

ამ HTML პროექტში ყურადღება გამახვილებულია **ცხრილების** შექმნასა და სტილიზაციაზე. პროექტის მიზანია სხვადასხვა ცხრილის სტრუქტურის შექმნის, ცხრილთან დაკავშირებული ტეგების გამოყენებისა და ელემენტარული inline CSS-ის გამოყენების პრაქტიკა.

- **`index.html`**: მთავარი გვერდი შეიცავს ორ ცხრილს:
  - **ცხრილი 1:** დამფუძნებლები და მათი ხელფასები
  - **ცხრილი 2:** სემინარის განრიგი

> [!NOTE]
> გვერდი არ არის ოპტიმიზირებული მობილური მოწყობილობებისთვის. საუკეთესო გამოცდილებისთვის გამოიყენეთ დესკტოპ ბრაუზერი.

## მიღებული გამოცდილება

- **ცხრილის სტრუქტურა**: სწორი სტრუქტურისა და ელემენტების ჩადგმის პრინციპების გაცნობა
- **ცხრილის სემანტიკა**: `<thead>`, `<tbody>`, `<th>`, `<td>` ტეგების გამოყენება სემანტიკისთვის
- **ცხრილის სტილიზაცია**: ელემენტარული inline CSS-ის გამოყენება საზღვრებისა და შევსებისთვის
- **გაფართოებული ცხრილის შესაძლებლობები**: `rowspan` და `colspan` ატრიბუტების გამოყენება რთული განლაგებისთვის

## გამოყენებული HTML ტეგები

### ცხრილის ელემენტები

- `<table>`: ცხრილის კონტეინერი
- `<caption>`: ცხრილის სათაური
- `<thead>`: ცხრილის თავსართი
- `<tbody>`: ცხრილის ძირითადი ნაწილი
- `<tr>`: ცხრილის რიგი
- `<th>`: ცხრილის სათაურის უჯრა
- `<td>`: ცხრილის მონაცემის უჯრა

### ცხრილის ატრიბუტები

- `rowspan`: უჯრების ვერტიკალურად გაერთიანება
- `colspan`: უჯრების ჰორიზონტალურად გაერთიანება
- Inline `style` ატრიბუტები საზღვრებისა და შევსებისთვის
