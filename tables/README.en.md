# Assignment 2.1: Working with Tables in HTML

[![Live Demo](https://img.shields.io/badge/Live-Demo-purple)](https://tbabl.github.io/it-academy-step-georgia-frontend-2022/assignment_02/tables/)

## Description

This HTML project focuses on creating and styling **tables** to display structured data. The purpose of this project was to practice implementing different table layouts, using table-related tags, and applying basic inline CSS for table styling.

- **`index.html`**: The main page contains two tables:
  - **Table 1:** Founders and their salaries
  - **Table 2:** Seminar schedule

> [!NOTE]
> This page is not optimized for mobile devices. For the best experience, please view it on a desktop browser.

## Lessons Learned

- **Table Structure**: Understanding the proper structure and nesting of table elements
- **Table Semantics**: Using `<thead>`, `<tbody>`, `<th>`, and `<td>` for semantic markup
- **Table Styling**: Applying inline CSS for borders and padding
- **Advanced Table Features**: Using `rowspan` and `colspan` for complex layouts

## HTML Tags Used

### Table Elements

- `<table>`: The container element for tabular data
- `<caption>`: To provide a title for the table
- `<thead>`: To group header content
- `<tbody>`: To group body content
- `<tr>`: Table row
- `<th>`: Table header cell
- `<td>`: Table data cell

### Table Attributes

- `rowspan`: To merge cells vertically
- `colspan`: To merge cells horizontally
- Inline `style` attributes for borders and padding
