პითაგორას თეორემა

პითაგორას თეორემა ყველაზე ცნობილი თეორემაა გეომეტრიის ისტორიაში და ალბათ ძნელად მოიძებნება ადამიანი, ვისაც მის შესახებ არ სმენია.
თეორემის ფორმულირება ასეთია:
მართკუთხა სამკუთხედის ჰიპოტენუზაზე აგებული კვადრატის ფართობი კათეტებზე აგებული კვადრატების ფართობების ჯამის ტოლია.
ანუ მარტივად რომ ვთქვათ - მართკუთხა სამკუთხედის ჰიპოტენუზას კვადრატი კათეტების კვადრატების ჯამის ტოლია. (იხ.სურათი)


პითაგორას თეორემის გრაფიკული ახსნა

სამართლიანია შებრუნებული მტკიცებულებაც:
თუ სამკუთხედის გვერდები a, b, c აკმაყოფილებენ პითაგორას თეორემის პირობას: a 2 + b 2 = c 2, მაშინ სამკუთხედი იქნება მართკუთხა, c გვერდის პირდაპირ მდებარე მართი კუთხით.

პითაგორას თეორემის დამტკიცება

მართკუთხა სამკუთხედში მართი კუთხის წვეროდან დაშვებული მართობი სამკუთხედს ყოფს მოცემული სამკუთხედის მსგავს ორ სამკუთხედად,
მსგავსი სამკუთხედების ფართობები კი ისე შეეფარდება ერთმანეთს, როგორც მსგავსი გვერდების კვადრატები.
სწორედ აქედან გამომდინარე ვიღებთ პითაგორას ფორმულას: a 2 + b 2 = c 2.
