# დავალება 3: ვებსაიტის განლაგების სტრუქტურის შექმნა

[![Live Demo](https://img.shields.io/badge/Live-Demo-purple)](https://tbabl.github.io/it-academy-step-georgia-frontend-2022/assignment_03/)

## აღწერა

ეს პროექტი ფოკუსირებულია HTML და CSS-ის გამოყენებით ვებსაიტის სტრუქტურირებული განლაგების შექმნაზე. მიზანი იყო ვებგვერდის სხვადასხვა სექციების იმპლემენტაციის, შინაარსის სემანტიკურად ორგანიზების და ელემენტების სტილიზაციისა და პოზიციონირებისთვის CSS-ის გამოყენება.

- **`index.html`**: მთავარი გვერდი, რომელიც შეიცავს სათაურს, რამდენიმე სექციას და ქვედა კოლონტიტულს
- **`styles.css`**: გარე სტილის ფაილი, რომელიც განსაზღვრავს განლაგებას და გარეგნობას

> [!NOTE]
> ეს გვერდი არ არის ოპტიმიზირებული მობილური მოწყობილობებისთვის. საუკეთესო გამოცდილებისთვის, გთხოვთ ნახოთ დესკტოპის ბრაუზერში.

## მოთხოვნები

- [x] სემანტიკური HTML ელემენტების გამოყენება (`<header>`, `<section>`, `<article>`, `<aside>`, `<footer>`)
- [x] CSS-ის გამოყენება სტილიზაციისა და განლაგების პოზიციონირებისთვის

## განლაგების სტრუქტურა

ვებსაიტი შედგება:

- **სათაური (Header)**: შეიცავს საიტის სახელს და ნავიგაციის მენიუს
- **მთავარი შინაარსი**:
  - პირველი სექცია ორი სტატიით
  - მეორე სექცია შინაარსით და გვერდითი ზოლით
  - მესამე სექცია შინაარსის სამი სვეტით
- **ქვედა კოლონტიტული (Footer)**: შეიცავს თარიღის ინფორმაციას

## შესწავლილი გაკვეთილები

- **სემანტიკური HTML**: დოკუმენტის უკეთესი სტრუქტურისთვის შესაბამისი HTML5 ელემენტების გამოყენება
- **CSS განლაგება**: float, display და პოზიციონირების თვისებების გამოყენება
- **ყუთის მოდელი**: margins, padding და borders-ის ეფექტურად მართვა
- **ტექსტის სტილიზაცია**: ტექსტის ფორმატირების სხვადასხვა ტექნიკების იმპლემენტაცია
- **ფერთა სქემები**: ერთიანი ფერთა პალიტრის შექმნა

## გამოყენებული HTML ელემენტები

- `<header>`: გვერდის სათაურისთვის, რომელიც შეიცავს ნავიგაციას
- `<nav>`: ნავიგაციის მენიუსთვის
- `<main>`: მთავარი შინაარსის კონტეინერისთვის
- `<section>`: დაკავშირებული შინაარსის დაჯგუფებისთვის
- `<article>`: დამოუკიდებელი შინაარსის ბლოკებისთვის
- `<aside>`: გვერდითი ზოლის შინაარსისთვის
- `<footer>`: გვერდის ქვედა კოლონტიტულისთვის
- `<div>`: დამატებითი შინაარსის დაჯგუფებისთვის

## გამოყენებული CSS ფუნქციები

- გარე CSS ფაილის დაკავშირება
- კლასის და ID სელექტორები
- ყუთის მოდელის თვისებები (margin, padding, border)
- ტექსტის სტილიზაცია (font-family, font-size, color და სხვა)
- განლაგების პოზიციონირება (float, display)
- ფონის ფერები და სტილიზაცია
