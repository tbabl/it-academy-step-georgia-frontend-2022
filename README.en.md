## Description

This is my first HTML project, where I created **two interconnected webpages** to explain the **Pythagorean Theorem** and **Pythagorean Numbers**. The purpose of this project was to practice using various HTML tags correctly and effectively to structure content.

- **`index.html`**: This page focuses on the **Pythagorean Theorem**, its formula, graphical explanation, and proof. It also includes an inverse proof of the theorem.
- **`pythagorean_numbers.html`**: This page explains **Pythagorean Numbers** (also known as Pythagorean triples), their properties, and the rules for generating them, including special cases for odd and even numbers.

Both pages are linked together, allowing users to navigate between the theorem and the numbers seamlessly. External links are also provided for additional information about Pythagoras.

> [!NOTE]
> This page is not optimized for mobile devices. For the best experience, please view it on a desktop browser.

## HTML Tags Used

In this project, I used a variety of HTML tags to structure and present the content effectively. Below is a list of all the tags I used, along with their purposes:

### Structural Tags

- `<!DOCTYPE html>`: Declares the document type and version of HTML.
- `<html>`: The root element of the HTML document.
- `<head>`: Contains meta-information about the document, such as the title and character encoding.
- `<title>`: Defines the title of the webpage, which appears in the browser tab.
- `<meta>`: Provides metadata about the HTML document, such as character encoding and keywords.
- `<body>`: Contains the visible content of the webpage.

### Text Formatting Tags

- `<h1>` to `<h6>`: Used for headings to structure the content hierarchically.
- `<p>`: For paragraphs to separate blocks of text.
- `<strong>`: For bold text to emphasize key points.
- `<em>`: For italicized text to add emphasis.
- `<b>`: For bold text (used for visual emphasis).
- `<i>`: For italicized text (used for emphasis or citations).
- `<small>`: For smaller text, often used for disclaimers or captions.
- `<ins>`: For underlined text to indicate additions.
- `<del>`: For strikethrough text to indicate deletions.
- `<mark>`: To highlight important text with a background color.
- `<sup>`: For superscript text, useful for mathematical notations like exponents.
- `<sub>`: For subscript text, useful for indices in mathematical formulas.
- `<br>`: For line breaks to control spacing.
- `<hr>`: To create horizontal lines for visual separation.

### Links and Navigation

- `<a>`: For hyperlinks to connect to external resources or other pages. Used with the `href` attribute to specify the destination.
- `target="_blank"`: Used in `<a>` tags to open links in a new tab.

### Images

- `<img>`: To embed images in the webpage. Used with the `src` attribute to specify the image source and `alt` for alternative text.

### Lists

- `<ul>`: For creating unordered lists.
- `<li>`: For list items within `<ul>` or `<ol>`.

### Special Characters

- HTML entities like `&lt;`, `&gt;`, and `&amp;` were used to display special characters.
