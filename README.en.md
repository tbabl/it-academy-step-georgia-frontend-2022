# Assignment 3: Creating Website Layout Structure

[![Live Demo](https://img.shields.io/badge/Live-Demo-purple)](https://tbabl.github.io/it-academy-step-georgia-frontend-2022/assignment_03/)

## Description

This project focuses on creating a structured website layout using HTML and CSS. The purpose was to practice implementing different sections of a webpage, organizing content semantically, and applying CSS for styling and positioning elements.

- **`index.html`**: The main page contains a header, multiple sections, and a footer
- **`styles.css`**: External stylesheet defining the layout and appearance

> [!NOTE]
> This page is not optimized for mobile devices. For the best experience, please view it on a desktop browser.

## Requirements

- [x] Use semantic HTML elements (`<header>`, `<section>`, `<article>`, `<aside>`, `<footer>`)
- [x] Apply CSS for styling and layout positioning

## Layout Structure

The website consists of:

- **Header**: Contains site name and navigation menu
- **Main Content**:
  - First section with two articles
  - Second section with content and sidebar
  - Third section with three columns of content
- **Footer**: Contains date information

## Lessons Learned

- **Semantic HTML**: Using proper HTML5 elements for better document structure
- **CSS Layout**: Applying float, display, and positioning properties
- **Box Model**: Managing margins, padding, and borders effectively
- **Text Styling**: Implementing various text formatting techniques
- **Color Schemes**: Creating a cohesive color palette

## HTML Elements Used

- `<header>`: For the page header containing navigation
- `<nav>`: For navigation menu
- `<main>`: For the main content container
- `<section>`: For grouping related content
- `<article>`: For self-contained content blocks
- `<aside>`: For sidebar content
- `<footer>`: For the page footer
- `<div>`: For additional content grouping

## CSS Features Used

- External CSS file linkage
- Class and ID selectors
- Box model properties (margin, padding, border)
- Text styling (font-family, font-size, color, etc.)
- Layout positioning (float, display)
- Background colors and styling
